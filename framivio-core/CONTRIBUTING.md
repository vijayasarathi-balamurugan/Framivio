# Contributing

1. Open an issue describing the problem or proposed improvement.
2. Keep changes focused on reusable geometry, validation, or tests.
3. Add or update tests for behavior changes.
4. Run `npm test` and the Java check before opening a pull request.
5. Do not submit API keys, signing files, private app code, user media, or third-party assets without permission and compatible licensing.

By submitting a contribution, you agree that it is provided under this repository's Apache-2.0 license.
