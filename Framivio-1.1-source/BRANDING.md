# Framivio

Display name: Framivio
Pronunciation: frame-ee-vee-oh
Descriptor: Photo & Video Resizer

Renamed from CreatorFit on 26 September 2026. App labels, screens, export names, output folders, store artwork and listing copy use Framivio.

Preliminary searches across two web search engines, including queries targeting Google Play and Apple's App Store, did not identify an exact-name app or brand conflict. A historical newspaper OCR result contains the string; unrelated approximate-name results also appeared. This is not proof of worldwide uniqueness, domain availability, social-handle availability or trademark clearance. No domain or name was registered.

The existing Android namespace/application-ID default (`com.vk.creatorfit`) and billing product ID (`creatorfit_pro_lifetime`) are intentionally retained for installation and purchase continuity. These are internal identifiers, not the display name. Keep the same configured application ID and signing key for updates to existing installations.

This is a source branding update. Android build and device validation remain pending as described in VERIFICATION.md.
